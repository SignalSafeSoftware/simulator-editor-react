# Editor 0.1.2 release

Editor 0.1.1 and its repository are public. Version 0.1.2 corrects conversation normalization: an already represented legacy last-activity timestamp is not reassigned to undated authored rows. Genuine legacy migration, chronology, stable IDs and delay values remain supported. Repeated read/write and paused learner Reply/Send are regression cases.

The React peer range supports both `^0.21.2` and `^0.22.0`. Development uses verified public core 0.7.3, React 0.22.0, simulator theme 0.13.5 and editor theme 0.3.8. The existing peer minimums are retained where compatible; no provider, API or runtime composition is imported into the editor.

The user authorized the coordinated release and existing deployment mechanisms. Publication uses `.github/workflows/release.yml`: a new matching `v0.1.2` tag, strict types, lint, formatting, complete coverage, build and packed smoke, then public npm publication with provenance. Existing tags remain immutable; there is no developer-machine publication.

Validate packed consumers against both supported React cohorts. Refresh genuine registry development and example locks only after upstream archives exist. Local review aliases are historical evidence and do not replace normal registry adoption. The example adopts editor 0.1.2 after its public archive exists; publication and successful host adoption are recorded separately.

## Patched development tooling and coverage

Vitest and its V8 coverage provider move together from 3.2.7 to 4.1.12 using the supported upstream dependency graph. This removes the development-only vulnerable worker/mock chain; the final normal npm audit reports zero vulnerabilities. No dependency override, forced peer installation, ignored diagnostic or lowered threshold is used.

The new V8 branch mapping initially reported 23 previously uncounted paths while all 186 existing tests still passed. This was a measurement change, not a newly introduced runtime defect. Sixteen meaningful keyboard, focus, selection-reset and malformed/stale callback regressions now cover the reachable paths. A private message-update helper receives its already guarded active conversation explicitly; generated child nodes retain typed owner/message-key metadata, so deletion does not decode a known generated JSON ID and repeat unreachable array/owner guards. Encoded IDs, external validation, authored ordering and the stale-node early return are preserved and independently reviewed.

Final results: 202 tests, 100% statements/branches/functions/lines, strict source/test types, lint/module and format checks, normal registry build and packed consumer checks. Both old React 0.21 and new React 0.22 peer cohorts remain supported; publication still requires current-head hosted verification and the matching immutable tag.
